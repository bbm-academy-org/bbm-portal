Справочники (редактируемые)

Валюта

  • код (RUB, THB, USDT…)
  • минимальная единица
  • точность (копейки / сатоши)

Счёт

  • название
  • тип: банк / карта / крипто / нал
  • валюта →
  • старт с нуля; история с самой первой операции (реш. 17)

Проект

  • название (Doctor.School, …)
  • «Фонд BBM» — особая строка
  • один уровень, без подпроектов (реш. 16)

Продукт (продаваемая единица)

  • проект →
  • название (урок, курс…)
  • цена продажи (если задана)
  • капитализация — считается из проводок (реш. 22)

Назначение расхода

  • название («аренда студии»…)
  • статья →
  • заявка выбирает отсюда, не текстом (реш. 21)

Статья расходов

  • название · подкатегория свободна
  • флаг: в себестоимость / расход периода
  • retired (не удаляется, уходит в архив)
  • стартует ПУСТОЙ — список выводится из факта (реш. 11)
Факт (неизменяемое ядро)

Операция

  • дата · назначение
  • источник → (заявка / банк / hours / вручную / бэкфилл)
  • флаг: перенесена задним числом
  • сторнирует → операцию (если сторно)
  • группа конвертации → (если обмен)

Проводка (двойная запись)

  • операция →
  • счёт →
  • дебет / кредит · сумма (bigint, мин. единицы)
  • валюта →
  • проект → (или Фонд)
  • статья → · продукт → (если относимо)
  • участник → (если персонально)

Группа конвертации

  • связанные проводки: ушло / пришло
  • комиссия каждого шага — своя проводка
  • курс, замороженный на дату операции
  • переоценивать ли крипто-остатки?

Обязательство (долг)

  • начислено, но не выплачено (команде)
  • возместить участнику (потратил своё)
  • видно в отчётах всегда (реш. 14)
Наполнение (источники)

Заявка на расход

  • участник → · проект →
  • сумма · валюта → · назначение
  • флаг «уже потрачено» (реш. 12)
  • документы → (инвойс, чек)
  • статус: ждёт / одобрена / отклонена
  • одобрил → · порождает операцию →
  • отказ — с причиной?

Документ

  • файл (инвойс, чек, выписка)
  • прикреплён к заявке / операции →

Импорт выписки

  • файл · банк · формат
  • кандидаты → дедупликация → разметка
  • ничего не проводится без подтверждения
  • какие банки/форматы в v1?

Начисления из /p/hours

  • закрытый период → операции ФОТ
  • ставка × часы · cash / invest части
  • повторное закрытие не дублирует
  • проводить по участнику или суммарно?
Производные (ничего не хранят)

Отчёты — чтение проводок

  • Реестр · P&L · Cash flow
  • Себестоимость единицы · Безубыточность
  • валюта отчёта переключаемая, RUB по умолчанию
  • курс — фактический, на дату операции (реш. 18)

Сверка с финмоделью

  • ожидание из SSOT: резерв %, сектора, роялти
  • факт из проводок · разрыв = число

Сценарий (план)

  • базлайн = факт на дату
  • строки-допущения: будущий расход / доход / цена
  • план НИКОГДА не смешивается с фактом (реш. 14)
  • базлайн пересчитывается при открытии (реш. 20)
Правила ядра (спека §8, не пересматриваем): двойная запись · проводки неизменяемы, исправление — сторно · суммы bigint в минимальных единицах · курс конвертации заморожен на момент операции.
