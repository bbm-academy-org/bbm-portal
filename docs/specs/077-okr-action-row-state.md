# Строка действия OKR-дашборда: честное состояние родителя — spec (issue #77)

## Why

Владелец увидел на `portal.bbm.academy/p/okr` задачу «Организовать сайт
конгресса ортобиологии, перелив трафика» как `1/1` с полностью залитой
полосой — то есть выполненную, — хотя в Plane она **In Progress**. Строка
действия с сабтасками показывает только roll-up детей и полностью умалчивает
собственное состояние родителя. Второе следствие той же развилки: сумма чисел
по строкам действий не сходится со счётчиком KR (в примере строки дают
`0/1` и `1/1` плюс два чипа, а KR показывает `1/6`), потому что KR считает
плоско — родители и дети одним множеством, — а строка считает только детей.

Арифметика прогресса при этом верна: `src/lib/okr/mapper.ts` уже кладёт
родителя в знаменатель KR как незакрытого. Чинится только отрисовка строки.

## Requirements

1. **Состояние родителя видно всегда.** Каждая строка действия показывает
   собственное состояние своей задачи в Plane отдельным чипом — независимо от
   того, есть у неё сабтаски или нет. Сегодня чип есть только у бездетных.
2. **Чип называет состояние честно, тремя значениями** — по группе состояния
   Plane: `completed` → «✓ готово», `started` → «◐ в работе»,
   `backlog`/`unstarted` → «○ не начато». Сегодня чип бинарный, и задача в
   статусе Todo подписана «в работе».
   *(Расширение относительно исходного симптома; владелец подтвердил его
   вместе с остальным спеком 2026-07-29 — «го, со всеми пунктами». Следствие
   принято сознательно: в DSG2 большинство задач в Todo, поэтому на дашборде
   появится много «не начато» там, где раньше стояло «в работе».)*
3. **Счётчик строки считает родителя единицей работы.** Когда у действия есть
   сабтаски, `сделано/всего` и полоса берутся по множеству «сам родитель +
   его сабтаски» (отменённые исключены, как и везде): в примере
   «Организовать сайт конгресса» → `1/2`, а не `1/1`.
4. **Числа сходятся снизу вверх.** Сумма единиц по всем строкам действий KR
   равна счётчику KR: строка с сабтасками даёт свои `всего`, строка без
   сабтасков — единицу, состояние которой назвал чип. В примере
   `0/2 + 1 + 1/2 + 1 = 1/6` — ровно счётчик KR.
5. **Бездетная строка не обзаводится счётчиком и полосой** — у неё только
   чип, как сегодня: `0/1` читается суше, чем «в работе», и ничего не
   добавляет.
6. **Полоса всегда соответствует своему числу.** Залита ровно на
   `сделано/всего` этой же строки; никаких «кэпов» и подкрашиваний, у которых
   число и полоса расходятся.
7. **Ограничения вёрстки — те же, что в спеке 075:** страница остаётся без
   клиентского JS (native `<details>/<summary>`); hover не меняет метрики
   строки; на узких экранах кластер индикаторов переносится целиком и не
   обрезается карточкой (`.okr-card{overflow:hidden}`).
8. **Модель прогресса не меняется.** `mapper.ts`/`rollup.ts` продолжают
   считать KR/Objective/Goal плоско по всем issue модуля; проценты на
   дашборде после правки те же.

## Acceptance scenarios

Все — на живом стенде `https://portal.bbm.academy/p/okr` (вход через Zitadel).

1. Развернуть KR «Кол-во регистраций на вебинарах» (карточка
   «Канал/приложение имеет достаточный для монетизации охват»): строка
   «Организовать сайт конгресса ортобиологии, перелив трафика» показывает
   чип «◐ в работе» и счётчик `1/2` с полосой, залитой наполовину — задача
   больше не читается как выполненная.
2. В той же строке нажать иконку ↗: в Plane открывается **DSG2-11** в статусе
   **In Progress** — ровно то, что сказал чип.
3. Сложить единицы по всем четырём строкам этого KR: получается `1/6` —
   ровно счётчик, который KR показывает в свёрнутом виде.
4. Строки без сабтасков («Мигрировать запланированные мероприятия…»,
   «Подготовить программу конгресса ОртоБио 2027») показывают только чип, без
   счётчика и полосы.
5. Закрыть в Plane любую задачу и через ~10 минут (TTL снапшота) обновить
   страницу: чип этой строки становится «✓ готово», счётчик и полоса
   родительской строки сдвигаются, процент KR — тоже.
6. Сузить окно до мобильной ширины: чип и счётчик с полосой переносятся
   вместе, ничего не обрезается и не выезжает за карточку.
7. Провести мышью по строкам: подсветка появляется, но текст не
   перескакивает и элементы не смещаются.

## Out of scope

- Модель прогресса и roll-up (`mapper.ts`, `rollup.ts`), светофор здоровья,
  метрики из `metrics.yaml` — считают верно, не трогаются.
- Структура досок в Plane: неполная декомпозиция DSG2-11 (сделано ТЗ, сам
  сайт — нет) — вопрос владельцев досок, не дашборда.
- Показ третьего уровня (сами сабтаски) отдельными строками — сегодня их
  видно только числом; отдельная задача, если понадобится.
- Автообновление открытой вкладки (real-time) — как и в спеке 075.
- Редизайн: палитра, структура экрана, направление вёрстки не пересматриваются.
